# Ad Fraud Pacing Monitor

One-line summary: Monitoring tooling for ad fraud and pacing anomalies in campaign data.

## Overview
Contains scripts and notebooks to detect pacing issues and potential ad-fraud signals using rule-based and statistical checks. Includes examples for alerting and reporting.

## Tech stack
- Python, Pandas
- Statistical anomaly detection and time-series monitoring

## Quickstart
1. Clone the repo
2. `pip install -r requirements.txt`
3. Run `src/monitor.py` or open notebooks in `notebooks/`
